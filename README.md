# ASP.NET-Core-MVC-CRUD-Application-With-Entity

## About the Project

This project is a CRUD (Create, Read, Update, Delete) web application developed using ASP.NET Core MVC and Entity Framework Core. It uses the Code First approach to manage database operations and LINQ queries to retrieve and manipulate data.

The project helped me practice backend development, database connectivity, routing, and form validation in ASP.NET Core MVC.

## Technologies Used

- C#
- ASP.NET Core MVC
- Entity Framework Core
- LINQ Queries
- SQL Server
- Code First Approach
- HTML, CSS, Bootstrap
- Data Annotations for Validation

## Features

- Create new student records
- Read and display student records
- Update existing records
- Delete records
- Database operations using Entity Framework Core
- LINQ queries for data retrieval
- Form validation
- MVC routing and controller actions
- Razor Views for the user interface
- Success messages using TempData

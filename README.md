# ASP.NET-Core-MVC-CRUD-Application-With-Entity

It allows users to manage student records through CRUD (Create, Read, Update, and Delete) operations.

This project was developed to strengthen my understanding of ASP.NET Core MVC architecture, database connectivity, server-side validation, and data management using Entity Framework Core.

## 🚀 Technologies Used

- **Programming Language:** C#
- **Framework:** ASP.NET Core MVC
- **ORM:** Entity Framework Core
- **Database:** Microsoft SQL Server
- **Query Language:** LINQ
- **Frontend:** HTML5, CSS3, Bootstrap
- **View Engine:** Razor Views
- **Validation:** Data Annotations
- **Database Approach:** Code First

## ✨ Features

- **Create Student Records** — Add new students to the database.
- **View Student Records** — Display student information in a structured table.
- **Update Student Information** — Edit existing student records.
- **Delete Student Records** — Remove records from the database.
- **Entity Framework Core Integration** — Perform database operations using EF Core.
- **LINQ Queries** — Retrieve and manipulate data efficiently.
- **Form Validation** — Validate user input using Data Annotations and model validation.
- **MVC Architecture** — Organize the application using Models, Views, and Controllers.
- **Razor Views** — Build dynamic web pages using Razor syntax.
- **Success Messages** — Display operation feedback using TempData.
- **MVC Routing** — Navigate between controller actions and application pages.
